# Scanzo — Premium QR Studio

A responsive, monochrome QR code generator landing page built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive navigation and animated section reveals
- Large interactive hero QR matrix with per-module hover distortion on pointer devices
- QR content modes: Website, Text, hosted PDF link, hosted image link, Contact card (vCard), and Email
- Customisation controls for dot style, corner style, QR colour, background colour and error correction
- Large live preview with SVG download, PNG download and Copy SVG actions
- How-it-works, feature, CTA and FAQ sections
- Keyboard focus states and reduced-motion support

## Run locally
Open `index.html` in a browser. QR generation and fonts use CDN-hosted libraries, so an internet connection is required.

## Important file-link note
A QR code cannot contain a whole PDF or image file. For PDF and image modes, upload the file to a public file host first and paste its shareable URL. Scanzo does not upload files to a server.

## Publish on GitHub Pages
Upload the contents of this folder to the root of the Scanzo repository, preserving `css/`, `js/`, and `images/` paths.
